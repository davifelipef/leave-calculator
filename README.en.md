# Leave Calculator

[Versão em Português](README.md)

## Overview

Leave Calculator is a web application designed to calculate
the return-to-work date after a period of leave.

## Features

- Calculation of the return-to-work date.
- Identification of the corresponding day of the week.
- Simple and intuitive interface.
- No installation required.
